# **App Name**: ConnectFlow Pro

## Core Features:

- Consultant Profile Editor: Authenticated consultants can log in, view their existing profile, update their personal details, professional experience, skills, and upload/update their CV.
- Consultant Directory & Search: A centralized, searchable table view for administrators to see all registered consultants. Includes key data points (Name, Last Name, Latest Update, Country, CV link) and basic Name/Last Name search, along with a total row count.
- Advanced Filtering System: Implement dynamic filtering for the consultant directory based on key criteria like Country of Residence, Profession/Discipline, Languages, and Sectors of Experience.
- Opportunity Listing: A dedicated module where consultants can view a list of available opportunities, each with brief descriptions and details.
- CV Document Previewer: Allow administrators to preview uploaded CV documents directly in a new browser tab without requiring a download, enhancing quick review workflows.
- Secure User Authentication: Implement a secure system for consultant and administrator registration, login, and session management, including role-based access.
- AI-Powered CV Insight Tool: Utilize generative AI as a tool to automatically extract and summarize key skills, experiences, and qualifications from uploaded consultant CVs for administrators.

## Style Guidelines:

- Primary color: A sophisticated, trustworthy blue (#2666A6) to represent professionalism and clarity.
- Background color: A very light, subtly desaturated blue-gray (#F0F2F4) to provide a clean and calm canvas.
- Accent color: A vibrant turquoise (#3CDDDD) to highlight interactive elements and call-to-actions, ensuring visual contrast and engagement.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly readable qualities suitable for professional data display and forms.
- Use a consistent set of clean, modern line icons for navigation, data actions (e.g., search, edit, view), and filters, promoting an efficient user experience.
- Employ a structured, dashboard-style layout with a prominent, collapsable sidebar for navigation and filters, and a spacious main content area for data tables and profile details. Emphasize clear hierarchy and organization.
- Incorporate subtle, functional animations for feedback on interactive elements (e.g., button hovers, form submissions) and smooth transitions during data filtering or pagination.
